LAB5 — SECURE HTTPS SERVER & KRIPTO-SECURITY
Hardware lab5:

    Мікроконтролер ESP32-C3 (WeAct Studio): Використовується як обчислювальне ядро, здатне виконувати ресурсомісткі криптографічні операції (RSA-шифрування, TLS-хендшейк) у реальному часі.

    Вбудована Flash-пам'ять: Використовується для зберігання сертифікатів безпеки X.509 (server.crt), приватного ключа (server.key) та статичних ресурсів вебінтерфейсу через файлову систему LittleFS.

    Wi-Fi модуль: Забезпечує бездротовий канал зв'язку для передачі зашифрованого TLS-трафіку між контролером та браузером.

    USB-інтерфейс: Служить для живлення пристрою та виводу налагоджувальної інформації (Debug logs) про процес SSL-рукостискання.

ПЗ та бібліотеки lab5:

    mbedTLS: Потужна криптографічна бібліотека, інтегрована у фреймворк Arduino. Забезпечує реалізацію стека TLS v1.2, керування ентропією (RNG), парсинг сертифікатів та симетричне шифрування (AES-GCM).

    LittleFS: Файлова система для автономного зберігання захищених сторінок login.html та dashboard.html. Дозволяє відокремити логіку безпеки від візуального представлення.

    lwip/sockets: Використання низькорівневих сокетів Berkeley для створення TCP-сервера на стандартному HTTPS порті 443 та керування дескрипторами клієнтів.

    Basic Authentication: Програмний механізм перевірки облікових даних через декодування заголовка Authorization (Base64), що обмежує доступ до /dashboard та /api/status.

Frontend технології:

    HTML5 / CSS3: Веб-інтерфейс з адаптивним дизайном, що включає сторінку авторизації та захищену панель керування з темною темою.

    SessionStorage: Використовується у браузері для тимчасового зберігання токенів авторизації (credentials) протягом поточної сесії.

    Fetch API (Secure): Реалізує асинхронні запити до захищеного API контролера. Оскільки сервер використовує самопідписаний сертифікат, реалізовано підтримку TLS на стороні клієнта.

    JSON Serialization: Обмін даними про стан системи (/api/status) відбувається у зашифрованому форматі JSON, що гарантує цілісність та конфіденційність інформації.
