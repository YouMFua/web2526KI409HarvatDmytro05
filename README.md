LAB4 — WI-FI CAPTIVE PORTAL & NVS STORAGE
Hardware lab4:

    Мікроконтролер ESP32-C3 (WeAct Studio): Виступає в ролі інтелектуального мережевого вузла, що підтримує два режими: Access Point (AP) для конфігурації та Station (STA) для основної роботи.

    Енергонезалежна пам’ять (NVS): Використовується для надійного зберігання облікових даних Wi-Fi (SSID та пароль) навіть після вимкнення живлення пристрою.

    Wi-Fi модуль: Забезпечує створення власної точки доступу з фіксованою IP-адресою 192.168.4.1 для автоматичного доступу до порталу налаштувань.

    USB-інтерфейс: Використовується для живлення та моніторингу процесу підключення через Serial-порт.

ПЗ та Бібліотеки lab4:

    LittleFS: Сучасна файлова система, що використовується для зберігання файлу portal.html, що дозволяє розмежувати логіку сервера та дизайн інтерфейсу користувача.

    Preferences.h: Бібліотека для зручної роботи з NVS-пам'яттю через пари "ключ-значення", що забезпечує збереження налаштувань між перезавантаженнями.

    DNSServer.h: Ключовий компонент для реалізації перехоплення запитів. Він перенаправляє будь-який DNS-запит (*) на IP-адресу контролера, що змушує смартфони автоматично відкривати сторінку налаштувань.

    WebServer.h: Реалізує HTTP-сервер на порті 80, обробляє запити для видачі форми налаштування та прийому нових параметрів через POST-запит.

    WiFi.h: Керує режимами роботи радіомодуля (AP/STA) та процесом аутентифікації в домашній мережі.

Frontend:

    Captive Portal Logic: Реалізовано обробку специфічних системних URI (наприклад, /generate_204), які Android та iOS використовують для автоматичного виявлення точок доступу з авторизацією.

    Modern UI: Веб-сторінка налаштувань розроблена з використанням адаптивного дизайну, що забезпечує зручне введення SSID та пароля на мобільних пристроях.

    Fetch API: Використовується для відправки конфігураційних даних на сервер без перезавантаження сторінки, надаючи користувачеві зворотний зв'язок про успішне збереження.
